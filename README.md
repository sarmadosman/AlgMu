Prerequisite: set up your IAC Driver by following this video: https://www.youtube.com/watch?v=MkWZ4rtRybQ

In order to use this (Mac):
1. Open Ableton
2. In settings -> Link, Tempo & MIDI -> Input/Output ports: toggle IAC Driver (Bus 1) Track and Remote.
3. Create 4 MIDI Instruments: bass (MIDI from Jazz Bass Out), drums (MIDI from Jazz Drums out), piano 1 (MIDI from Jazz Piano Out),
and piano 2 (MIDI from Computer Keyboard, MIDI to IAC Driver (Bus 1)).
